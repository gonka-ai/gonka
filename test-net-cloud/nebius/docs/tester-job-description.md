# Gonka Quality Assurance Engineer

## **Remote · Contract**

This role offers an opportunity for a talented **QA/infrastructure testing engineer** to join the Gonka team.

You will work with distributed nodes and services in production-like environments, helping validate network upgrades, inference and Proof-of-Compute flows, host and broker interactions, and other critical changes before they reach mainnet.

This is a hands-on infrastructure and backend testing role that involves a considerable amount of automation. You should be comfortable deploying services, investigating system behavior through logs and metrics, and turning findings into clear test results and defect reports.

## About the project

[Gonka](https://gonka.ai) is a decentralized AI compute network that connects developers with independent GPU hosts and provides OpenAI-compatible access to AI inference.

You will be working alongside the team that built the chain from the ground up. You will also liaise and partner with external contributors who support the Gonka project.

## Responsibilities

- Create test plans and acceptance criteria for network components and releases.
- Run smoke, regression, end-to-end, edge-case, and negative tests.
- Deploy and validate nodes and services in production-like environments.
- Test critical flows involving participants, hosts, brokers, gateways, inference, and Proof-of-Compute.
- Investigate failures using logs, metrics, health signals, and chain queries.
- Verify upgrades, rollback procedures, recovery scenarios, and post-change health.
- Report defects with clear reproduction steps, evidence, impact, and expected behavior.
- Document test results, practical operational settings, and release-readiness findings, and contribute relevant findings to the official Gonka documentation where appropriate.

## Required experience

- 3+ years of experience in system QA, test engineering, SDET, infrastructure testing, or quality-focused DevOps/SRE.
- Experience testing backend, infrastructure, or distributed systems.
- Ability to design practical test plans and investigate system failures.
- Solid Linux, SSH, shell scripting, Docker, and log analysis skills.
- Ability to write clear defect reports and technical documentation.
- Working English: enough to read technical documentation and write comprehensive test reports and defect write-ups (all project artifacts are public and in English).
- Interest in blockchain networks and willingness to learn node operations quickly (prior Cosmos SDK experience is a strong plus).

## Nice to have

- Experience operating or testing blockchain nodes, especially Cosmos SDK-based networks.
- Familiarity with RPC and chain queries, synchronization, recovery, key management, delegated permissions, or fee grants.
- Experience with CI pipelines, scripted validation, automated health checks, or container orchestration.
- Experience with coordinated multi-node upgrades, rollback testing, API gateways, or proxies.
- Experience with GPU/ML inference or decentralized inference networks.

## Interview process

1. **Introductory interview — 30 minutes**  
   Relevant experience, previous projects, expectations, and availability.

2. **Technical interview — 60–75 minutes**  
   Discussion of previous infrastructure and testing work, followed by practical testing and troubleshooting scenarios.

3. **Interview with the founding team — 60 minutes**  
   Meet the people who started the project. Discussion of the direction, how you would work with the hiring team and external contributors, and your questions about Gonka.
