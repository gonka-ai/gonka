# Security

Submit every security vulnerability through the [HackerOne form](https://gonka.ai/docs/report-vulnerability/). That is the only intake.

- Do not open a public GitHub issue or pull request.
- Do not post the issue in Discord or other public channels.

A valid report is paid after triage. A fix can be paid separately; that amount is discussed individually.

Full program: [Bounty program](https://gonka.ai/docs/bounty-program/).
